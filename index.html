Weeks 1–12

Progression rule

Double progression: stay at the listed load/resistance until you can complete every working set at the top of the rep range with ~2 RIR and clean form. Then increase one step next time: BL1 +1 level when practical; dumbbells move to the next pair, or first add reps/tempo/unilateral difficulty when the 15→25 lb jump is too large.

Warm-up & rest

Start with 4–5 minutes of easy movement plus one light practice set for the first upper- and lower-body movement. Rest ~90 sec after big movements and 45–75 sec after smaller accessory/core work. Superset paired exercises when noted to stay under an hour.

One-time Google Cloud setup
  1. Create or select a Google Cloud project.
  2. Enable the Google Drive API.
  3. Configure the OAuth consent screen for your Google account.
  4. Create an OAuth Client ID of type Web application.
  5. Add the HTTPS address where you host this tracker to Authorized JavaScript origins.
  6. Paste that Client ID above and click Connect Google Drive.
